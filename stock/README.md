# Stock fallback assets

No fal.ai key? Use a ready-made set instead of rendering. Each set has 2 videos + 3 images.

    ./use-stock.sh warm   mybrand   # then ./build.sh

Sets: **warm** (liquid gold), **cosmic** (nebula), **ember** (lava/forge).
Match your `site.config.mjs` palette and copy to the set you pick.
